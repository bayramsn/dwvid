# Evrensel Video İndirici

Bu uygulama ile YouTube, Twitter, Instagram, TikTok, Vimeo gibi binlerce siteden video indirebilirsiniz.

## Kurulum
1. Python yüklü olduğundan emin olun.
2. Gerekli kütüphaneleri kurun: `pip install -r requirements.txt`
3. Uygulamayı çalıştırın: `python app.py`
4. Tarayıcınızda `http://localhost:5000` adresine gidin.
